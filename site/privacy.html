Privacy

This site is a set of static HTML pages. In plain terms:

  • Advertising and affiliate links: this site does not currently serve any ads. The pages carry publisher site-verification meta tags (Mitgo/Admitad and Impact) so that ownership of this domain can be confirmed by those networks. A verification tag is not an ad: it sets no cookie, loads no script and collects nothing. Outbound links to insurers' own sites are ordinary citations and are not affiliate links. If ads or affiliate links are ever added, this page will be updated first to name the network and its data practices.
  • This site itself runs no analytics and no tracking pixels of its own.
  • No account, no login, no form on this site collects personal data (the contact page links to an email address and the public repository).
  • Hosting: Cloudflare Pages serves the pages and processes standard server logs (IP address, user agent, requested path) for security and abuse prevention, per Cloudflare's privacy policy.
  • Quoted prices and links point to the insurers' own sites; once you click through, their privacy policies apply.

Questions about this policy: see the contact page. Facts last checked 2026-09-25.
