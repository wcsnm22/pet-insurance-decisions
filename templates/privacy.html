Privacy

This site is a set of static HTML pages. In plain terms:

  • Advertising: this site does not currently serve any ads. The pages carry publisher site-verification meta tags for ad networks so that ownership of this domain can be confirmed by those networks; a verification tag is not an ad and sets no cookie. If ads are ever added, this page will be updated first to name the network and its data practices.
  • This site itself runs no analytics and no tracking pixels of its own.
  • No account, no login, no form on this site collects personal data (the contact page links to an email address and the public repository).
  • Hosting: Cloudflare Pages serves the pages and processes standard server logs (IP address, user agent, requested path) for security and abuse prevention, per Cloudflare's privacy policy.
  • Quoted prices and links point to the insurers' own sites; once you click through, their privacy policies apply.
